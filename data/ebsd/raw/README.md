# Raw EBSD data

`ban.ctf` is the raw Channel Text File used for the manuscript calculations. The file header records 239 x 227 measurement cells with 0.405 micrometre spacing in both in-plane directions.

This file is included so that the segmentation and boundary-polyline construction can be rerun from the measured input rather than from a rendered image. Do not edit it in place. Its byte-level identity is recorded in the repository SHA-256 manifest.
